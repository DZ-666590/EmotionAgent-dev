================================================================================
PROTOCOL DETAILS
================================================================================

TCP Stream Structure (from C++ service):
  [4 bytes] frame_index (uint32)           ← Frame number
  [4 bytes] geo_size (uint32)              ← Count of float32 elements
  [N bytes] geometry (float32[geo_size])   ← Actual geometry data (N = geo_size*4)
  
End Marker: frame_index = 0xFFFFFFFF (signals no more frames)

Data Size Calculation:
  Per-frame bytes = 8 + (geo_size * 4)
  Example: geo_size=252 → 8 + (252*4) = 8 + 1,008 = 1,016 bytes
  
Expected geo_size Range: 50-1,000 (typical facial models)
