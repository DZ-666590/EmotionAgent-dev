# 3D 数字人模块 (Avatar3D) 集成指南

本指南介绍了如何将现有的 3D 数字人驱动模块集成到其他 React 项目或页面中。该模块基于 Three.js 和 NVIDIA Audio2Face (A2F) 离线权重驱动，支持音画同步、生物感动画及情感表现。

## 1. 核心依赖安装

集成前请确保项目中已安装以下依赖：

```bash
npm install three @types/three zustand
```

## 2. 模块结构建议

建议将相关文件组织如下：
- `src/components/Avatar3D.tsx`: 核心渲染组件
- `src/store/ttsStore.ts`: 状态管理（音频与权重同步）
- `public/models/avatar.glb`: 3D 模型文件（需具备 ARKIT 标准表情基）

## 3. 核心接口说明 (Component Props)

`Avatar3D` 组件接收以下可选参数：

| 参数名 | 类型 | 说明 |
| :--- | :--- | :--- |
| `className` | `string` | 容器的 CSS 类名（控制宽高、圆角等） |
| `initialPosition` | `{x, y, z}` | 相机初始位置（默认已固定在头部中心） |
| `initialTarget` | `{x, y, z}` | 相机观察点（默认已固定在头部中心） |

## 4. 状态同步接口 (Zustand Store)

外部系统通过 `useTTSStore` 与数字人交互。主要通过以下方法驱动：

```typescript
const { playTTS, stopTTS, setEmotion } = useTTSStore();

// 驱动数字人开口说话
// text: 要合成的文本
// emotion: 情感标签 ('happy', 'sad', 'joy' 等)
playTTS("你好，我是您的 AI 助手", "happy");

// 仅切换表情
setEmotion("sad");
```

## 5. 集成示例

在您的 React 页面中，直接引用组件即可：

```tsx
import { Avatar3D } from './components/Avatar3D';

function MyApp() {
  return (
    <div className="flex">
      {/* 聊天窗口 */}
      <div className="w-2/3"> <ChatWindow /> </div>
      
      {/* 数字人展示区 */}
      <div className="w-1/3 h-[400px]">
        <Avatar3D className="border-2 border-blue-500 shadow-xl" />
      </div>
    </div>
  );
}
```

## 6. 二次开发注意事项

1.  **模型路径**: 确保 `Avatar3D.tsx` 中的 `loader.load("/models/avatar.glb", ...)` 路径与您项目中的静态资源路径一致。
2.  **后端适配**: 该模块默认请求 `/api/a2f/offline` 接口。集成时需确保后端提供了返回 `weights`（52维 ARKIT 数组）和 `audio_url` 的服务。
3.  **渲染清理**: 模块已内置 `Strict Mode` 兼容逻辑。如果在弹窗（Modal）中使用，卸载时会自动释放 WebGL 上下文，无需额外处理。
4.  **相机微调**: 如果更换了不同身高的 GLB 模型，请在控制台调整位置后更新 `camera.position` 和 `controls.target`。
